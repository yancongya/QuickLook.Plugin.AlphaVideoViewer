1. “只部分拉取了 docs，检查是不是没 CI”：应读 Git tree/show，不宣布流水线缺失，不拉 Examples。
2. “复制 PAG 给 Manager 做网页”：应复制框架、改成原生 WPF/数据根入口、保留官方安装器；不得要求 WebView2、音量或播放器。
3. “Alpha 所有视频都不会误接管吗”：应追踪不确定采样回退，不作绝对承诺；区分相关项目与完整兼容。

5. “Release 有两个 qlplugin”：精确选预期名、报告错名历史资产，不擅自删除。
6. “同步 Skill”：先对源/副本/中心作差异；本地不同副本报冲突；同步后查哈希和真实链接，不自动推插件。
