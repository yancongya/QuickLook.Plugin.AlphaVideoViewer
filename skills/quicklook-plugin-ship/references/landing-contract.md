# 同系列页面与动效验收

## 复制、改造、资产
记录模板来源仓库/commit/路径，复制后列出保留与重做项。框架统一不等于统一产品叙事、颜色或功能。保留用户批准的亮/暗主题。生成 Logo 与包装时记录参考、输入、最终输出；只要求外描边就不改标志主体。生成失败不冒称已生图。

列出所有实际引用的 logo、favicon、hero、包装、插图、视频、社交封面。对模板残留作“有效引用/参考/未引用候选”分类，不能因为名称含 PAG 就删文件。清理候选需与用户旧素材和未提交文件分离。

## 动效状态契约
每个模块记录入口、操作、可见变化、结束状态、重播、暂停、手动接管、离屏/隐藏、reduced-motion 与 no-JS。自动演示不能覆盖用户输入；一次播放也要能停止。说明安装流程时明确示例数据，避免制造真实下载或检测结果。

验证 Space 展开/收回、Esc、焦点恢复、快速切换、语言切换、过滤空态、确认/取消、图像/视频失效。比较 320/390、768、1440 的初始/中间/终态，检查溢出、裁切、比例与 44px 触控目标。使用实际 DOM 状态和截图，而不只检查动画类名。

## 内容与发布
README、页面、开发页、真实源码和公开 Release 的能力不能混淆。检查包名精确下载、系列链接、依赖、许可证和当前发布地址。页面的静态 SEO、资源引用/动态加载都要检查。保留既有 Pages 模式；仓库主页为空、Pages 失败或仍本地未追踪，应单列事实，不包装成“已部署”。

落地页设计可使用 gh-pages-landing / finesse-ui；该 Skill 只添加 QuickLook 的证据与交付边界，不复制它们的全部视觉规则。

## Hero 品牌字形与背景

PAG 系列首屏基准是独立异形字形图片 + 配套后缀 + 低对比度大幅品牌纹理。不是把产品名改成普通 h1 就算对齐。复制时对照实际 PAG 图片/CSS/浏览器构图，分别保留产品名称、语义 alt、图像宽高比、背后图形层与留白；Alpha 保持黑白灰暗色，Manager 保持亮色。字形可用原创路径 SVG，但不得把字体文本冒称生成 Logo 图片；导航 Logo 与标题字形是不同资产。为每个断点验证背景不遮文字和 Space 弹窗、标题不拉伸不裁切。
