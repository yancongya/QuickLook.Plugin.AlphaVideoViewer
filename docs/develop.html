项目把 .NET 宿主、探测层与 WebGL 合成器分开。你可以调整播放器界面、扩展识别规则，或重写合成数学，再在 Windows 的 QuickLook 中验证。

获取源码 → 构建 → 打包
# Clone
git clone https://github.com/yancongya/QuickLook.Plugin.AlphaVideoViewer.git
cd QuickLook.Plugin.AlphaVideoViewer

# Build
dotnet build -c Release

# Package on Windows
powershell -ExecutionPolicy Bypass -File Scripts/build.ps1

需要 Windows 构建环境与 .NET Framework 4.6.2 目标框架支持。打包后，将 .qlplugin 装回 QuickLook 验证。
